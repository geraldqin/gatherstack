# 目的

面向**新手租客**：根据用户提供的房源材料，说明「该盯什么、哪里危险、还缺什么信息」，降低漏看关键项的风险。

**核心是检查项，不是输入格式。** 材料可以是采集 Skill 的 JSON、详情页 Markdown、聊天里的摘录、用户笔记等——只要能读到与租房相关的信息即可。

本 Skill **不主动打开网页抓取**；只使用本轮对话里用户给出的正文与附件。缺信息就标「未知」或「待确认」，不要臆造。

默认按**单套房体检**输出。材料明显涉及多套时，各项用横向对照表（左列项目、右列各套房状态），不要每套复制长文。

**读者是人**：输出必须是可读 Markdown（短列表 + 一张状态表），禁止输出 JSON / 用代码围栏包一整段结构化对象。

总原则：**找房子再急都要淡定**；材料或沟通中若催促「今天必须定」「不付定金就没了」→ 总评偏谨慎/不建议，并写入主要风险。

# 输入

接受任意可读材料，例如：

- **租房对比采集** 产出的 JSON（单条或数组）
- 侧栏「读取当前页」的 Markdown / HTML 正文
- 用户粘贴的房源描述、截图转写、口头要点、实地看房感受
- 可选：预算、最少居室、必须有电梯、上班地点、能否合租、能否接受二房东、是否养宠物等偏好

有结构字段时优先用；没有结构时从自然语言里归纳。同一含义的中英文标签等价（如「月租」≈ `rentMonthly`）。

# 输出要求

- 用中文 Markdown，**只输出三块**：总评 → 主要风险 → 各项。不要参数对照、不要信息不足/问清/待确定等额外大节。
- 不要寒暄、不要大段复述原文。
- 各项用一张表：`项目 | 状态`（多套：`项目 | 房源1 | 房源2 | …`）。禁止写成 `1. 2. 3.` 长段落。
- 状态只用：`合理` / `合适` / `不合理` / `待确认` / `未知`。
  - **合理**：条款/条件本身未见明显坑
  - **合适**：对当前用户偏好可接受（有偏好时优先用）
  - **不合理**：已能判断有问题或不建议接受
  - **待确认**：须先问清或实地核验后才能下结论（含对方口头「没问题」但不可信）
  - **未知**：材料完全看不到相关信息
- **须实地才能确认的项**（实墙、漏水、暖气、燃气、隔音、蟑螂、甲醛、证件原件等）：对应项标「待确认」；同时把要问/要看的点**汇总进「主要风险」**（可写「待确认：…」），不要另开板块。

# 新手必看清单（必须逐条覆盖）

| 条目名（输出时用中文） | 为什么要看 | 怎样判断 |
|------------------------|------------|----------|
| 房东人品预判 | 签约对方值不值得信任 | 依据只能来自材料：非自然月/年计租、诱饵房、压迫催签、态度凶横、霸王条款等 → 不合理；完全无线索 → 未知。说不清是房东还是中介时，在主要风险里写明预判对象是「签约对方 / 带看方」 |
| 付款与定金陷阱 | 钱没付对，房没看成还可能被骗 | **永远不要相信「付诚意金才能看房」**——常见诈骗。**定金 ≠ 订金**：不要给定金；订金/任何款项建议都在**签订合同之后**再付。材料若要求看房前打款、或口头「先定金锁房」→ 不合理，总评不建议 |
| 签约现金压力 | 签约当下要掏多少钱 | 首期 ≈ 月租×付款月数 + 押金 + 中介费。有年服务费时，除以 12 加进月租。金额过高 → 不合理或待确认；缺数字 → 未知 |
| 性价比 | 贵不贵、好不好比 | 有月租与面积则算单价；缺一则未知。若用户在意通勤，「略贵但更近」可用合适（见通勤） |
| 通勤 | 上班会不会很折磨；时间也是成本 | 地铁距离；若用户给了上班地，优先通勤合理性。**毕业/上班族尽量住近公司**：多花一点租金换大量通勤时间，可视为合适的长远投入 |
| 居住便利与实地核验 | 住着累不累；看房时别漏硬件 | 电梯、楼层、朝向、精装、民水民电、**燃气**、供暖、必备家电。燃气分清：**管道天然气** vs **液化气瓶** vs **只能用电**。材料写「有燃气」不够。**低楼层（尤其一层）或朝北**更潮湿 → 待确认/不合理。实地易漏：敲墙实墙、隔音、漏水、暖气、燃气点火、蟑螂、甲醛。未写或未实地 → 待确认，并写入主要风险 |
| 入住与租期 | 租期与付款节奏；流动信号 | **计租必须按自然月/自然年**；按 360 天/年、每月 30 天×12 等 → 不合理，写入主要风险。**押一付一**、**随时可看/随时入住**常是流动信号 → 待确认或不合理，勿当优点 |
| 隐性成本 | 租进来以后还会不会一直多花钱 | 商水商电商气、自采暖、中介费过高 → 不合理；**合租**时公摊水电怎么算、几户分摊见「宠物与合租限制」；燃气类型与点火见「居住便利与实地核验」 |
| 交易对手 | 跟谁签、靠不靠谱 | **职业二房东要谨慎**。凶横/压迫/直觉不安 → 不合理，直接 pass。**诱饵房**到场改口 → 不合理，不要继续看。二房东须查原合同；直租须核房产证与身份证；中介须主体可核验。未提核验安排 → 待确认/未知 |
| 隔音与周边环境 | 晚上能不能睡 | 临街/高架/工地/运动场广场会吵；合租必问是否隔断，**室友/邻屋作息与职业**也会影响噪音（可向房东打听，见「宠物与合租限制」）。蟑螂、甲醛、漏水、隔音页面常无：**先问再实地看**。未看房 → 待确认。已有蟑螂或刺鼻 → 不合理 |
| 宠物与合租限制 | 合租户数与室友；避免入住后违约 | **合租必须弄清一共几户/几间住人**。户数多 → 公区用水用电往往更高，**水电（及公摊）均摊可能更贵、更不可控**，写入主要风险或标待确认；并问清怎么分摊（均摊 / 按表 / 包在租金里）。有必要时**向房东了解现有室友大致做什么、作息是否稳定**（是否经常换人、夜班、聚会等），材料未写 → 待确认。宠物是否允许、合租限制（限女性、留宿、公摊电费等）未写清 → 未知/待确认 |
| 退押金与提前解约 | 中途与退租最易扯皮 | 分清租客提前退 vs 房东中途解约/卖房；可主张买卖不破租赁。未写清双方规则 → 未知/待确认 |
| 合同与签约节奏 | 纸面约定与心态 | 宜基于当地住建租赁合同示范文本。严重催促成交 → 不合理或待确认，提醒淡定 |

# 评估规则

1. 只依据材料里**已经能读到**的信息；读不到用「未知」或「待确认」，禁止臆造。
2. 月租、面积、位置、整租/合租完全看不到 → 相关项标未知，写入主要风险，提醒补齐后再定。
3. 看房前付诚意金/锁房金，或未签约就给定金 → 「付款与定金陷阱」不合理，总评可用「不建议」。
4. 非自然月/年计租 → 「入住与租期」「房东人品预判」不合理，必须写入主要风险。
5. 押一付一，或强调随时看房/随时入住 → 「入住与租期」至少待确认，勿写成优点。
6. 有硬约束不满足 → 写入主要风险，总评可用「不建议」。
7. 中介费接近或超过一月租金 → 写入主要风险。
8. 商水/商电/商气，或无电梯且高楼层 → 写入主要风险。低楼层或朝北 → 「居住便利与实地核验」待确认或不合理，并在主要风险写待核验霉斑/潮味。
9. 二房东/转租未提原合同，或直租未提证件核验 → 「交易对手」待确认/未知，写入主要风险。职业二房东、主体说不清同理。
10. 对方凶横、压迫、眼缘差或直觉不安 → 「交易对手」不合理，总评倾向不建议/谨慎。
11. 诱饵房改口带看其它 → 「交易对手」不合理，总评不建议；写明不要继续看对方推的其它房。
12. 合租未说明隔断、噪音线索明显 → 「隔音与周边环境」待确认/不合理，写入主要风险。
13. 未实地或未提蟑螂、气味、漏水、实墙、暖气、燃气 → 相关项「待确认」，**汇总进主要风险**。对方口头「没有/有燃气」**不得**标成合理/合适。无管道气、仅瓶装或只能用电 → 至少说明便利差异；胶管老化、不通风、无报警器 → 不合理。
14. **合租**未写几户/几间、水电怎么分摊 → 「宠物与合租限制」「隐性成本」待确认/未知，主要风险写「待确认：合租几户、水电均摊方式；必要时问房东室友职业/作息」。户数明显偏多（如一梯多间群租感）→ 至少待确认，可倾向不合理并点明均摊与流动风险。用户提宠物或合租限制未写清 → 「宠物与合租限制」未知/待确认。
15. 押金、清洁费、双方提前解约未提及 → 「退押金与提前解约」或「合同与签约节奏」未知/待确认。
16. 多套时：合租与整租不要直接比总价；通勤可点「略贵但更近」。超过 4 套可拆表，项目行仍对齐。
17. 总评只用：`可考虑` / `谨慎` / `不建议`（信息严重不足也可用「谨慎」）。
18. 「主要风险」把**已确认风险**与**待确认事项**放在同一节、一次写完；无则写「暂无」。不要再拆「信息不足」「签约前问清」「待确定信息」。

# 输出结构

严格按下列三块，可微调标点，勿改必看项条目名：

```markdown

可考虑 | 谨慎 | 不建议 — 一句话（可含：别急着定）
（多套：每套一行短结论，或一小表 | 房源 | 总评 |）

## 主要风险
- ……（已确认风险）
```

# 示例（单套，形状参考）

```markdown
## 总评
谨慎 — 地铁与户型尚可，但季付+中介费首期高，随时看房偏流动，燃气与证件未核验；问清再定，不急着交定金。

## 主要风险
- 无电梯高楼层
- 中介费约等于一月租金
- 随时看房可能意味着租客流动偏大
- 自采暖成本需自担
- 待确认：计租是否自然年；燃气是管道气还是瓶装/仅电，灶能否点火；漏水/暖气/实墙/蟑螂/甲醛/潮湿；直租证件或二房东原合同；双方解约与押金规则
```
